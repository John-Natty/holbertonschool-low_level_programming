# C - Structures, typedef

## Description

This project introduces the concept of **structures (`struct`)** and **type definitions (`typedef`)** in the C programming language.

Structures allow grouping multiple variables of different types into a single unit, making it easier to represent real-world objects in programs.   The `typedef` keyword helps simplify complex type declarations by creating aliases.

Throughout this project, we learn how to define structures, access their members, use pointers with structures, and simplify their usage with `typedef`.

---

## Learning Objectives

At the end of this project, you should be able to explain, without the help of Google:

* What structures are  
* When, why and how to use structures  
* How to use `typedef`

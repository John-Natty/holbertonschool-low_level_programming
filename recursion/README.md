# C - Recursion

## Description

This project introduces the concept of **recursion in C programming**.

Recursion is a programming technique where a function **calls itself** in order to solve a problem. Instead of using loops, a recursive function breaks a problem into **smaller subproblems** until it reaches a **base case** where the recursion stops.

The goal of this project is to understand how recursion works, how to implement it in C, and in which situations it is appropriate to use it.

---

## Learning Objectives

At the end of this project, you should be able to explain:

* What recursion is
* How to implement recursion in C
* In which situations recursion should be used
* In which situations recursion should **not** be used

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* All files will be compiled on **Ubuntu 20.04 LTS**
* Compilation will be done using:

```
gcc -Wall -Werror -Wextra -pedantic -std=gnu89
```

* All files must end with a new line
* A `README.md` file at the root of the project is mandatory
* Code must follow the **Betty coding style**
* Code will be checked using `betty-style.pl` and `betty-doc.pl`
* No use of **global variables**
* No more than **5 functions per file**
* The use of the **standard library is forbidden**

  * Functions such as `printf`, `puts`, etc. are not allowed
* The only allowed output function is `_putchar`
* You do **not** need to push `_putchar.c`
* Header file prototypes must be included in `main.h`
* **Loops are forbidden** (`for`, `while`, `do...while`)
* The use of **static variables is forbidden**

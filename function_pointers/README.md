# C - Function Pointers

## Description

This project introduces **function pointers in C** and demonstrates how they can be used to create flexible and dynamic programs. Function pointers allow functions to be passed as parameters, stored in structures, and called dynamically.

The project explores several important concepts such as:

- Function pointers
- Callback functions
- Iterating through arrays with function pointers
- Searching using comparison functions
- Implementing a calculator using a **table of function pointers**

---

## Learning Objectives

At the end of this project, you should be able to explain:

- What function pointers are and how to use them
- What a function pointer holds
- Where a function pointer points to in memory
- How to use function pointers as arguments
- How to create and use arrays of function pointers
- How to build modular programs with multiple C files
